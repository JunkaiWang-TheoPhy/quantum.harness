# Exact D6 physical-channel bound design

## Objective

Raise the certified resource ratio beyond
`11791/2851 = 4.1357418449...` by tightening the rigorous D6 contribution.
Physical interpretation is used to discover a stronger norm certificate; it
is not a substitute for an improved adjacent-integer PASS/FAIL result.

## Physical object

The frozen fourth-order Suzuki formula has a right-generator expansion whose
degree-six term D6 is determined by the next nontrivial effective-Hamiltonian
correction.  Its Pauli strings represent overlapping-bond, multi-spin exchange
processes generated by nested Heisenberg commutators.

The baseline certificate applies a Pauli-l1 bound.  This assumes that every
Pauli channel can attain its extremum simultaneously.  Spatially overlapping
Pauli channels frequently anticommute, so that assumption is unnecessarily
conservative.  For an exactly pairwise-anticommuting group,

```text
|| sum_j c_j P_j || <= sqrt(sum_j |c_j|^2).
```

This is both a physical statement about incompatible multi-spin error channels
and a rigorous operator-norm inequality.

## Data and trust boundary

Two independent E7 fanout layouts, 544 and 272 shards, must reconstruct the
same complete canonical D6 coefficient map.  Equality means identical
metadata, Pauli-key set, exact cubic-field coefficient at every key, rational
l1 value, and recorded payload SHA-256 values.  A single completed lane is
provisional and cannot change the certified ratio.

The grouping certificate consumes only the cross-validated D6 payload.  Cubic
coefficients are enclosed by outward rational intervals before norm bounding.
Groups are discovered heuristically but certified by exact symplectic
anticommutation checks.  Terms not admitted to a group remain singleton terms,
so coverage is complete and the result remains an upper bound.

## Analysis pipeline

1. Validate and compare the independent 544- and 272-shard D6 payloads.
2. Decode the canonical Pauli coefficient map and reconstruct lattice support.
3. Classify terms by support size, connected spatial cluster, bounding box, and
   lattice-symmetry orbit for interpretation and deterministic grouping.
4. Build pairwise-anticommuting groups, retaining every ungrouped term as a
   singleton.
5. Certify exact coverage, uniqueness, interval containment, and pairwise
   anticommutation; compute both Pauli-l1 and grouped bounds.
6. Bind the tighter D6 sidecar by path and SHA-256 into the existing ledger.
7. Search integer steps without assuming improvement, reporting the accepted
   integer and the immediately preceding rejected integer.

## Quantitative gates

With the other frozen ledger terms unchanged, the D6 site-bound thresholds are:

| D6 site bound | Integer result | Resource ratio |
|---:|---:|---:|
| `<= 4824.21` | `r = 94` | `11791/2821 ~= 4.179724x` |
| `<= 3017.49` | `r = 93` | `11791/2791 ~= 4.224651x` |
| `<= 1310` | `r = 92` | `11791/2761 ~= 4.270554x` |

No improvement is claimed unless the complete ledger accepts the new integer,
rejects the preceding integer, and passes the verifier chain.

## Verification and failure behavior

The implementation must test exact cross-lane comparison, missing/duplicate
term rejection, coefficient tampering, group tampering, sidecar path/SHA
binding, and deterministic regeneration.  Fast verification is followed by
focused tests, deep verification, and a clean reproduction when time permits.

The workflow is fail-closed:

- one D6 lane: provisional diagnostic only;
- unequal full maps: no sidecar and no multiplier update;
- grouped bound fails to beat l1: retain the valid l1 result;
- no integer boundary crossing: retain the certified `4.1357418449...x`;
- deep or clean reproduction incomplete: label any improved result candidate.

## Deliverables

- cross-lane comparison audit with both payload hashes;
- deterministic D6 physical-channel/grouping sidecar;
- verifier tests and tamper-rejection evidence;
- updated adjacent-integer certificate if and only if it passes;
- a concise physical explanation tying the reduction to incompatible
  multi-spin exchange-error channels;
- a PR comment that clearly distinguishes certified, candidate, and negative
  outcomes.
