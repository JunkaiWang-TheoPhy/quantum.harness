\begin{abstract}
This supplement records a six-hour, proof-directed HPC sprint for Issue 128.
Before using any new HPC result, a post-freeze D5 sidecar was integrated into
the global error ledger and independently verified.  It accepts 95 steps,
rejects 94, and certifies the exact resource ratio
$11791/2851=4.135741844966678\ldots$.  The production phase computes exact
right-generator coefficients through complementary monolithic and 31-way
stage-sharded paths.  Every accepted artifact is canonical, SHA-256-bound,
source-identified, and checked by a verifier that can reject malformed
coverage, algebra, provenance, boundary, or resource arithmetic.  No
fivefold result is asserted.
\end{abstract}

\section{Certified result and research gate}

For the periodic $12\times12$ isotropic Heisenberg benchmark at $T=1$ and
global operator-norm tolerance $10^{-6}$, the certified fourth-order Suzuki
post-freeze result accepts $r=95$ and rejects $r=94$.  With
$G(r)=30r+1$ merged group exponentials, the exact resource ratio is
\[
  \frac{G(393)}{G(95)}=\frac{11791}{2851}
  =4.135741844966678\ldots .
\]
The exact global bounds are $9.90449140283245\times10^{-7}$ at 95 and
$1.04680611656037\times10^{-6}$ at 94.  The D4 and D5 sidecars contain 75,324
and 605,832 canonical Pauli terms, respectively, and both are independently
checked for complete coverage and pairwise anticommutation within every
group.  The original ten-file package remains frozen at 97 steps and is not
silently rewritten.

Fivefold arithmetic would require $r\le78$, but the present D4 contribution
alone is already approximately $1.259084\times10^{-6}$ there.  Thus an exact
D8 coefficient, even if zero, cannot close fivefold performance under the
current nonnegative ledger.  A new multiplier may be reported only after a
complete global ledger and independent fast/deep verification succeed.

\section{Exact sharding algorithm}

For stages $V_j(t)=\exp(-i a_j t H_{c_j})$ in the fixed 31-stage formula,
linearity gives a decomposition of the right generator into 31 contributions.
Each array task starts from $a_jH_{c_j}$ and conjugates it through all later
stages, truncating only the formal series degree at eight.  Coefficients live
exactly in $\mathbb{Q}[\alpha]/(\alpha^3-4)$; Pauli operators are canonicalized
under the $2\times2$ translation cell before serialization.

The shard format does not expose process-local registry bit indices.  Every
Pauli string is encoded by physical integer coordinates and labels.  Canonical
JSON and gzip with fixed metadata make repeated output byte-deterministic.
The manifest records stage, order, timestamps, term counts, peak RSS, source
commit, dirty flag, and SHA-256.  The reducer rejects a missing stage, wrong
formula/order, mixed source state, corrupt hash, or duplicate stage.  It also
requires forward and reverse exact reduction to produce identical maps.

For a cubic coefficient $c=a_0+a_1\alpha+a_2\alpha^2$, an outward rational
interval for $\alpha=\sqrt[3]{4}$ encloses $c$.  Summing the larger endpoint
magnitudes yields a rigorous Pauli-$\ell_1$ upper bound.  This bound is a
screening ingredient; it is not by itself the global $r=78$ certificate.

\section{Verification evidence}

The final local regression gate reported 109 passing tests and 11 deselected
slow tests in 74.04 seconds.  The D5-integrated fast verifier returned
\texttt{valid=true}; the deep verifier regenerated every D4/D5 coefficient
from the 31-stage formula, returned
\texttt{deep\_proof\_regenerated=true}, and completed in 167.62 seconds with
1.53~GB peak RSS.  A detached clean worktree repeated the fast verifier,
focused certificate tests, and every delivery SHA-256 check.

The independent remote verification job is recorded without hiding a mixed
outcome: its deep verifier passed, while the encompassing pytest command
returned nonzero.  Five failures were caused by the synchronized remote tree
lacking usable Git metadata; one pre-existing slow symplectic discovery test
returned a different numeric value.  This remote pytest result is not called
``all green'' and is not used to replace the successful local certificate
gate.

The exact-D8 array provides a useful scale check.  Stage 25 completed in
7349.722 seconds with 17,211,714 degree-eight terms and 52.15~GB peak RSS;
its output digest is
\texttt{c64c0729a1ef\ldots a95a4eb3cf7b}; the full digest is retained in the
machine-readable sprint log.
The order-six fallback uses the same stage-shard contract but truncates at D6.
Its reducer requires all 31 manifests, verifies each payload digest, and
requires forward and reverse exact sums to agree.  A compact parent manifest
binds every source shard and the reducer implementation before the exact D6
sidecar can enter the main certificate.

An additional cross-order replay job compared the degree-six maps embedded in
the independently generated order-six and order-eight shards for stages
25--30.  All six exact maps agreed term by term, covering 710,298, 446,094,
150,858, 2,028, 48, and zero terms, respectively.  This check compares
canonical Pauli keys and exact cubic-field coefficients rather than only a
reported norm.

The matching-order array is a separate discovery lane.  Its JSON records
\texttt{trusted=false} and states that its purpose is discovery ranking.  A
favorable ranking can nominate a formula for exact reconstruction but cannot
enter the certificate directly.

\section{Final adjudication protocol}

The outcome will be classified as follows.
\begin{enumerate}
  \item If all 31 shards and exact reduction succeed, insert the resulting D8
        upper bound into a complete $r=78$ ledger and rerun fast/deep checks.
  \item If any task reaches OOM or walltime, retain successful shards and
        scheduler evidence, retry only missing cells if time remains, and make
        no inference from a partial sum.
  \item If the complete ledger is at most $10^{-6}$, prepare a new independently
        bound certificate before describing a fivefold result.
  \item Otherwise publish the strict negative result or remaining numerical
        gap, while keeping the certified 4.135742-fold result unchanged.
\end{enumerate}

\textbf{Claim status.}  The currently accepted result is the independently
verified 4.1357418449-fold D5-integrated certificate.  Running D6/D8 work is
research evidence only until its artifacts, exact ledger, adjacent-step
boundary, hashes, and deep regeneration all pass.
