# Extensive calibrated spectral obstruction

## Statement

Let

```text
H_L = sum_<uv> (X_u X_v + Y_u Y_v + Z_u Z_v)/4
```

on the periodic even `L`-by-`L` square lattice, let `N=L^2`, and let `E5_L`
be the fifth-degree logarithm coefficient of the frozen five-copy
fourth-order Suzuki formula with the four matching fragments in the order
`0,1,2,3`. Write `tau(A)=Tr(A)/2^N`.

For every even `L >= 6`, define

```text
W_L = H_L^2 - (3N/8) I + H_L/2.
```

Then

```text
[W_L,H_L] = 0,
tau(W_L) = 0,
tau(W_L H_L) = 0,
```

and the exact leading-defect pairing is

```text
tau(W_L E5_L) = (N/4) q,

q = -7807/3600000
    - (66043/57600000) alpha
    - (6119/7200000) alpha^2,
alpha^3 = 4.
```

The three rational coordinates of `q` are not all zero. Since `x^3-4` is
irreducible over the rationals, `q != 0`. Consequently

```text
E5_L not in image(i ad_H_L) + span(I,H_L)
```

for every even `L >= 6`. The leading obstruction therefore survives endpoint
conjugation, global phase, and global time/energy calibration.

This is a leading-order logarithmic obstruction. The finite-step eigenphase
claim remains conditional on the branch and remainder criterion below.

## Exact moment proof

Normalized Pauli strings are orthonormal under `tau`. There are `2N`
nearest-neighbor bonds and three Pauli axes per bond, each with coefficient
`1/4`. Hence

```text
tau(H_L^2) = 2N * 3/16 = 3N/8.
```

For the bond operator `h=(XX+YY+ZZ)/4`, its triplet and singlet eigenvalues
are `1/4` and `-3/4`, so `tau(h^3)=-3/32`. The square lattice has no triangles;
no product on three distinct bonds contributes to the identity. Therefore

```text
tau(H_L^3) = 2N * (-3/32) = -3N/16,
-tau(H_L^3)/tau(H_L^2) = 1/2.
```

For `L >= 6`, fourth-moment identity products fall into four graph types:

| Graph type | Multiplicity | Sum over orderings |
|---|---:|---:|
| one bond used four times | `2N` | `21/256` |
| two distinct bonds, disjoint | `C(2N,2)-6N` | `27/128` |
| two distinct bonds, sharing a vertex | `6N` | `15/128` |
| four distinct edges of one plaquette | `N` | `9/32` |

Adding them gives

```text
tau(H_L^4) = (27N^2 - 21N)/64.
```

The `L=4` torus has additional wraparound coincidences and is deliberately
excluded. Substitution into `tau(W_L^2)` yields

```text
tau(W_L^2) = 9N(2N-3)/64 > 0.
```

Thus `W_L` is a nonzero commutant witness orthogonal to both allowed scalar
calibration directions.

## Exact local-density pairing proof

Every Pauli term in a depth-five matching commutator arises from a connected
cluster containing a base bond and at most four successive overlapping bonds.
The canonical `E5` density is therefore finite range. Pairing with `H_L` or
`H_L^2` retains only Pauli strings generated by one or two bonds, so the
contributing neighborhood is independent of `L` once `L >= 6`.

The exact finite local enumeration contains 74,448 nonzero `E5` density terms
over `Q(alpha)`. Sparse Pauli orthogonality gives the per-two-by-two-cell
identities

```text
tau(H_L E5_L)/(N/4)
  = 3589/2400000
    + (30361/38400000) alpha
    + (2813/4800000) alpha^2,

tau(H_L^2 E5_L)/(N/4)
  = -8399/2880000
    - (71051/46080000) alpha
    - (6583/5760000) alpha^2.
```

Their combination with coefficient `1/2` is exactly `q` above. The torus
lifting code independently reconstructs the full Hamiltonian before accepting
each size. Exact records at `L=6,8,10,12` agree coordinate by coordinate;
`L=4` is rejected by the coordinate-alias detector.

The local enumeration plus the finite-range argument establishes the formula
for the full even family `L >= 6`; the four stored sizes are independent
machine checks of that argument, not a floating-point extrapolation.

## Normalized obstruction

Define the squared dual lower bound

```text
rho_L = tau(W_L E5_L)^2 / tau(W_L^2)
      = 4N q^2 / (9(2N-3)).
```

It is an exact element of `Q(alpha)`. In particular,

```text
lim_(L -> infinity) rho_L = 2 q^2/9
                           ~= 8.35099162871e-6,
```

so the normalized obstruction does not vanish in the thermodynamic limit.
The exact verified values decrease from approximately `8.71408e-6` at `L=6`
to `8.43890e-6` at `L=12`, approaching this positive limit.

## Finite-step promotion gate

Suppose a common Hermitian logarithm branch has been established and the
calibrated total-time-one effective defect can be written as

```text
Delta_r = E5_L/r^4 + R_r
```

modulo `image(i ad_H_L)+span(I,H_L)`. Cauchy--Schwarz for normalized
Hilbert--Schmidt trace gives

```text
|tau(W_L R_r)| <= sqrt(tau(W_L^2)) sqrt(tau(R_r^2)).
```

Therefore the leading spectral obstruction provably survives whenever

```text
tau(R_r^2) < rho_L/r^8.
```

For `L=12`, the corresponding Hilbert--Schmidt norm thresholds are
approximately

| steps `r` | `sqrt(rho_12)/r^4` |
|---:|---:|
| 78 | `7.84810e-11` |
| 95 | `3.56655e-11` |

These are thresholds, not current remainder bounds. The present operator-norm
error ledger is not silently substituted for `tau(R_r^2)`: the logarithm
branch, normalization, and all-order remainder must first be made compatible.

## Evidence and proof levels

1. **Analytic identities:** commutation, calibration orthogonality, the second,
   third, and fourth moments, `tau(W_L^2)`, and the normalized family formula.
2. **Exact computer-assisted local identity:** the two cubic-field per-cell
   pairings obtained from the complete 74,448-term density enumeration.
3. **Independent finite-torus checks:** exact `L=6,8,10,12` records, complete
   matching reconstruction at every size, and explicit rejection of `L=4`.
4. **Still missing:** a compatible finite-step local-log branch and certified
